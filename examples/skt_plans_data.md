# SKT 5G 및 LTE 요금제 상세 데이터
(기준일: 2024-2025년 최신 요금제 구조)

## 1. 5G 일반 요금제 (5GX 라인업)

### 5GX 플래티넘
* **월 이용료**: 125,000원
* **데이터**: 완전 무제한
* **테더링/쉐어링**: 120GB 통합 제공 (테더링 60GB, 공유 60GB 한도 등 세부 조건 적용 가능)
* **음성/문자**: 기본 제공
* **프리미엄 혜택**: 
  - T우주 구독 2종 무료
  - VIP 멤버십
  - 스마트기기 (워치/패드) 2회선 무료

### 5GX 프라임
* **월 이용료**: 89,000원
* **데이터**: 완전 무제한
* **테더링/쉐어링**: 60GB 통합 제공
* **음성/문자**: 기본 제공
* **프리미엄 혜택**: 
  - T우주 구독 1종 할인/무료
  - VIP 멤버십
  - 스마트기기 1회선 무료

### 5GX 레귤러
* **월 이용료**: 69,000원
* **데이터**: 110GB (소진 시 최대 5Mbps 속도로 계속 사용)
* **테더링/쉐어링**: 기본 데이터 내에서 공유 가능
* **음성/문자**: 기본 제공

### 컴팩트 (2024년 신설)
* **월 이용료**: 39,000원
* **데이터**: 6GB (소진 시 최대 400Kbps 속도로 계속 사용)
* **테더링/쉐어링**: 기본 데이터 내에서 공유 가능
* **음성/문자**: 기본 제공

## 2. 5G 특화 요금제 (0 청년)
만 34세 이하 고객을 위한 청년 특화 요금제로 일반 5GX 대비 데이터 및 부가 혜택이 크게 강화되어 있습니다.

### 0 청년 69
* **월 이용료**: 69,000원 (5GX 레귤러와 동일)
* **데이터**: **160GB** (소진 시 최대 5Mbps) -> 일반 요금제 대비 +50GB
* **테더링/쉐어링**: 기본 데이터 내에서 공유 가능
* **청년 혜택**: 
  - 커피(주요 브랜드) 50% 할인 (월 1잔)
  - 영화관 50% 할인 (월 1회)
  - 로밍 요금 50% 할인

### 0 청년 49
* **월 이용료**: 49,000원
* **데이터**: **15GB** (소진 시 최대 1Mbps)
* **테더링/쉐어링**: 기본 데이터 내에서 공유 가능
* **청년 혜택**: 커피/영화/로밍 50% 할인 적용

## 3. LTE 요금제 (T플랜)
2025년 초부터 점진적으로 하위/구형 요금제의 가입이 중단되고 있으나, 여전히 사용되는 주요 LTE 라인업입니다.

### T플랜 맥스
* **월 이용료**: 100,000원
* **데이터**: 완전 무제한
* **테더링/쉐어링**: 가족 결합 시 '가족 공유 데이터' 80GB 제공
* **음성/문자**: 기본 제공

### T플랜 에센스
* **월 이용료**: 69,000원
* **데이터**: 100GB (소진 시 최대 5Mbps)
* **테더링/쉐어링**: 기본 데이터 내에서 공유 가능
* **음성/문자**: 기본 제공

### T플랜 안심 2.5G
* **월 이용료**: 43,000원
* **데이터**: 2.5GB (소진 시 최대 400Kbps) -> *2025년 2월 이후 신규가입 중단 예정*
* **음성/문자**: 기본 제공

### T플랜 세이브
* **월 이용료**: 33,000원
* **데이터**: 1.5GB
* **음성/문자**: 기본 제공 (영상통화 부가 100분)

## 4. 특별 할인 및 조건 (Condition & Benefit)

### 온가족할인 (가족 결합)
* **가입 조건**: 가족들의 SKT 가입 합산 기간이 30년 이상일 경우
* **혜택 내용**: 기본 월정액의 최대 30% 할인 (요금제 출시 시기에 따라 할인율 상이)

### 선택약정 할인
* **가입 조건**: 공시지원금 없이 12/24개월 약정 가입
* **혜택 내용**: 월정액 요금의 25% 할인 (다이렉트 전용 무약정 요금제는 제외)

### 다이렉트 5G (온라인 전용)
* **가입 조건**: 온라인(T다이렉트샵) 전용 무약정 가입
* **혜택 내용**: 약정 없이 기존 요금제 대비 약 30% 저렴하게 이용 가능 (예: 다이렉트 5G 27)
