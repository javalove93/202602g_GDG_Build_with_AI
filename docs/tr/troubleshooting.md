# Troubleshooting Log

이 문서는 프로젝트 개발 중 발생한 문제(Bugs), 에러, 그리고 그 해결 과정을 기록합니다. 비슷한 문제가 발생했을 때 참조하거나, 에이전트가 동일한 실수를 반복하지 않도록 가이드하는 용도로 사용합니다.

## 템플릿
### [YYMMDD] 이슈 제목
- **현상**: 에러 메시지나 비정상적인 동작 설명
- **원인**: 문제의 근본 원인 분석
- **해결**: 적용된 수정 사항 및 결과
- **교훈**: 향후 방지책
